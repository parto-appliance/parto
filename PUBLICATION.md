# Release verification

The release pairs the reviewed source with two appliance images. The release
metadata records the build-source commit and packaging checks. Verify your
download against `SHA256SUMS` before importing it.

See [third-party notices](THIRD_PARTY_NOTICES.md) for the licenses and sources of
bundled software. See the [deployment guide](docs/setup.md) for the supported
layouts and links to the hypervisor guides.
